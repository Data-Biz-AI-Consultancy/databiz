# 🧪 Tests

## ⚡ Quick Start

```bash
npm install
npx playwright install # First time setup
```

## 🏃‍♂️ Run Tests

```bash
npm run test           # Run all unit/DOM and backend API tests
npm run test:frontend  # Run Vitest unit/DOM tests for the frontend
npm run test:backend   # Run Vitest backend API tests (with mocked database)
npm run test:watch     # Run Vitest in watch mode (frontend only)
npm run test:e2e       # Run Playwright E2E browser tests
```
